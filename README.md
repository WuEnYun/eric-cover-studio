# Eric Cover Studio

把Eric的自媒体封面制作经验整理成可交接的AI技能：标题判断、字形审美、真实素材、本期人物、主视觉迭代，以及横竖画幅交付。

支持音乐Reaction、音乐制作、编曲教学、专业观点等内容。默认视频封面比例为16:9、4:3、3:4，常用像素为1920×1080、1600×1200、1080×1440。

## 包含什么

- 一个可安装的`eric-cover-studio`技能，入口在`skills/eric-cover-studio/SKILL.md`。
- 38条横版真实反馈文字，评级为S9／A23／B5／C1。
- 60张竖版筛选参考的编号与去除分享参数后的历史来源链接。
- 9张明确喜欢的历史附件的文字分析，以及已选／被否定／仅交付案例的区别。
- 本期输入卡、反馈记录模板、导出记录模板和无需第三方库的PNG技术检查脚本。

公开包只包含文字、索引和代码。给助理的完整版另含原始图片、已填写XLSX、案例、旧可编辑器与离线浏览页。两份技能核心文件相同；素材可选加载。

## 在支持技能的AI助手中使用

将`skills/eric-cover-studio`整个文件夹放到助手支持的技能目录。Codex常用用户目录为`~/.codex/skills/eric-cover-studio`；已有配置的环境按实际技能目录放置，不覆盖同名版本。重新开启会话后使用：

```text
请用 $eric-cover-studio 给这一期视频做封面。
这是本期视频、前采和人物截图；先给我看16:9主视觉，选择后出其他尺寸。
```

已有方向时：

```text
请用 $eric-cover-studio 基于我选定的蓝金版，直接做16:9、4:3、3:4三种尺寸，保留旧版。
```

在不支持技能目录的助手中，把SKILL.md与本期需要的参考文档交给助手读取。具体制图需要它所在环境可用的图像编辑／生成或排版工具；这份技能本身不提供模型或API密钥。

## 助理每期交付

本期输入卡 → 少量标题／视觉方案 → 主画幅选择 → 其他比例重排 → 实际图片与缩略图检查 → 版本化图片、导出记录及所需编辑源／ZIP。已经给出批量授权时沿用授权完成。

## 技术检查

```bash
python3 skills/eric-cover-studio/scripts/check_exports.py /path/to/episode/export-manifest.json
```

检查PNG结构、像素、比例、文件哈希，以及可选ZIP与旧文件哈希。审美、中文正确性、人物身份、题材准确性和用户审批仍需要实际检查。
