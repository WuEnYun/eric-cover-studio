# 助理素材包

安装助理完整版后，同一技能目录下有`assets/private/`。公开版本不含这个目录，规则、索引与技术检查脚本仍可使用。

| 相对位置 | 内容 |
|---|---|
| `assets/private/library.html` | 无联网依赖的参考浏览页，可按横版／竖版／历史喜欢／项目案例与评级筛选，查看反馈 |
| `assets/private/originals/Reaction横版封面审美反馈表.xlsx` | Eric已填写原件，38张图片与全部原始单元格，按字节复制保留 |
| `assets/private/horizontal/` | H01–H38，原始横版参考图，以稳定ID命名 |
| `assets/private/vertical/` | V001–V060，原始竖版参考图，未新增逐图评级 |
| `assets/private/liked/` | L01–L09，Eric明确喜欢的9张历史附件原图 |
| `assets/private/cases/` | 《至冬预言》、鸣潮、米哈游、渊下宫的选择／修正与技术案例，状态由清单给出 |
| `assets/private/contact-sheets/` | 原有横竖参考联系表与本次用于核对的历史喜欢／S级总览 |
| `assets/private/source-documents/` | 旧横版母版、竖版分析、旧编辑器说明；原件保留，内容层级为历史AI归纳 |
| `assets/private/tools/` | 历史46版HTML编辑器与参考背景／人物；能编辑文字、位置与尺寸，但旧默认字形不自动获认可 |
| `assets/private/asset-manifest.json` | 图片尺寸、SHA-256、评价来源、状态、相对路径 |
| `assets/private/source-provenance.json` | 仅助理版保留的原始文件路径与来源映射 |

打开浏览页查看参考，不需要把全部图加载进一次生成。按本期选3–5张，核对真实图像与反馈后再制作。浏览页提供对照，不提供制图能力。

本期视频、人物截图与题材素材仍需每次提供；历史编辑器素材不能替代本期输入。旧编辑器只有当年的字体与布局控件，不能保证当前每个设计方向都可从其还原。

给助理转交完整ZIP；上传GitHub使用独立公开ZIP。原始参考图、个人截图、带图片XLSX与分享token不在公开包内。原作者素材仅作内部学习与设计对照，没有自动转授素材公开再分发权。
