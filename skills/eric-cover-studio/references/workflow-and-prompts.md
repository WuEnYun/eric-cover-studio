# 多轮制作流程与可用提示词

## 新一期

从输入卡提取一个封面主张，核对本期人物、游戏／音乐作品、曲名、关键词和成片表达。前采文档可以有待校准判断，例如“四首二游”曾需要重新核对Fusion、摇滚与交响、音乐剧、波萨诺瓦等风格。未经核验的标题、背景和风格不进入确认层。

参考选择按本期用途进行：横版优先相关S样本及明确喜欢的成品；竖版从V001–V060里选相同内容类型。选3–5张时写明借鉴的是哪一处，如字形节奏、人物位置、颜色统一或缩略图信息，不把其他作者的人、Logo、标题与素材直接搬入。

默认先出2–3个实质不同方向：可以是字形与构图差异，而不只是换颜色。已选方向就继续该方向。不要每次重新读取全部历史或把所有98张图塞入一次生成；保存本期输入卡、参考ID、版本与修改记录，便于新线程接续。

## 制图工具选择

- 当前环境有图像生成／编辑工具时，先查看输入图片，再使用图片路径或实际附件引用。提示词里的素材路径并不保证模型真的收到图；以工具的参考图参数为准。
- 标题要求精准、需要助理修改或已有分层工具时，可用可编辑的文字层与真实图像合成。字体可用时检查授权和实际字形，不全局安装不明字体；不把未提供的字体称为已使用。
- 工具不可用时，可交付已完成的标题与设计说明、已有环境能制作的编辑源；明确还缺渲染步骤。文字方案不能被报告为已经出图。
- 历史HTML编辑器可用作方法参考，包含旧字形及素材配置；使用前确认默认素材与本期一致。助理版保留历史编辑器，当前审美要求优先于旧默认。

## 主视觉制作指令示例

下面是可填写的指令骨架，所有方括号由本期真实信息替换。

```text
为Eric的音乐Reaction视频制作 [比例与像素] 封面。
本期判断：[最终主张]。标题逐字使用：[中文标题]。
次要作品识别：[已核对的游戏／曲目关键词]。
人物参考：[本期真人截图]，保持脸、眼镜、耳机、手和表情的身份与自然结构。
题材素材：[真实关键帧／官方视觉]，保留 [本期能辨认的对象或地标]。
参考方向：[参考ID]，借鉴 [具体字形、图文关系或色彩结构]。
字要醒目、有设计感、在小图中可读。最大标题表达一个观点。
构图：[本期布局]；人物和标题分开，脸不被字或题材图压住。
避免：[本期已经被否定的具体处理]。
保持真实作品身份；不要凭空造一张相似游戏图替代实际内容。
```

真实人物与素材如被生成工具改作，记录为“基于参考的生成式编辑／合成衍生”；检查身份与题材一致性，不能写成像素完全不变。若要求人物原始像素不变，应使用支持原图图层锁定与准确合成的工具。

## 接收修改

把原话保存到独立追加记录，写出：版本、反馈原话、确认保留项、本轮修改项、适用范围。

| 触发反馈 | 本轮动作 |
|---|---|
| “字体不合适” | 换有实质差异的字形与结构，可先提供2–4个字体方向；不要仅加粗或微斜同一字体 |
| “背景不是这个游戏” | 核对真实来源和标志性对象，换实际截图／官方素材或明确的参考衍生，再与原素材对照 |
| “人脸和背景混在一起” | 恢复清晰主体、图层层级和分离度，检查脸与耳机；不要继续只调背景饱和度 |
| “用了不是这一期的截图” | 换成本期人物，重新检查姿态、遮挡和轮廓 |
| “拼贴痕迹太重，统一一张背景” | 本期采用连续单一背景，保留主标题和一个独立人物，不把此反馈反推到其他合集项目 |
| “基于这版出其他尺寸” | 记录所选版本，保持内容／气质，完成独立重排，无需再征询一次方向 |

## 其他比例指令示例

```text
基于已选择的 [主画幅文件]，重排为 [4:3／3:4与目标像素]。
保留主标题逐字内容、作品身份、Eric人物和 [已选择色调／字体气质]。
重新布置标题、人物、地标与关键词，目标构图：[布局]。
标题完整可读，脸不遮挡，无黑边，比例精确。不能直接裁切原横图代替构图。
另存新版本，并记录来源、原生尺寸、最终尺寸与实际处理方法。
```

## 交付

提供实际图片预览、最终文件、实际尺寸和必要的修改说明。需要可编辑源时让助理能够重新改标题、字形、字号、背景和人物位置；只交一张扁平PNG不满足这一需求。

用户选择与视觉检查记录分开。技术脚本成功后仍检查图片。新原话追加到`episode-feedback.csv`或同等记录中，保留原话；将可能复用的判断标为候选，待后续明确反馈再提升。原始XLSX的空白维持空白。

## 本技能的验收场景

1. 给一段本期视频和人物截图：应先核对主张与素材，按方向出主画幅；不会默默借用旧期人物。
2. 说“43版字体不行”：应识别其历史否定状态，保留素材与布局，明显更换字形，尚未选定时先展示主画幅。
3. 说“蓝金版做三个尺寸”：应沿用该选择并完成尺寸，无额外方向确认；最终像素检查不会把1672×941说成精确16:9。
4. 给多人多曲合集：可选多素材，按主题建立清晰层级；不会把《至冬预言》的单背景修正扩成全账号禁令。
5. 仅安装公开包：应能读文字规则与索引；不会声称本地已拥有私有参考图或可用人物素材。
